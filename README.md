## Description

A multi-page website with a navbar that covers all tasks of the assignment. Built with HTML5, CSS3, Bootstrap 5.3.3 (CDN) and vanilla JavaScript.

| Page | Tasks |
| --- | --- |
| `index.html` | Part 1: Task 0 (first script, console, alert), Task 1 (variables & operators) |
| `dom.html` | Part 2: Task 2 (changing content), Task 3 (changing styles), Task 4 (add/remove list items) |
| `events.html` | Part 3: Task 5 (mouse events), Task 6 (keyboard events), Task 7 (calculator) |
| `todo.html` | Part 4: Task 8 (interactive to-do list) |

## How to run

1. Clone the repository or download it as a ZIP.
2. Open `index.html` in a browser (no build step or server required).
3. Press `F12` and open the Console on the first page to see the output of Task 0 and Task 1.
